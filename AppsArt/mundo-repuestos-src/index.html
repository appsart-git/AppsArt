Antes de arrancar, elegí cómo vas a guardar los datos.

Los datos quedan guardados solo en este navegador. Podés conectar Firebase más adelante desde Configuración sin perder lo cargado (se puede exportar/re-importar).

Conectar base de datos compartida (Firebase)

Para que el celular del mostrador y la PC vean el mismo stock y las mismas cuentas en tiempo real:
  1. Entrá a console.firebase.google.com con una cuenta Google, creá un proyecto nuevo.
  2. Dentro del proyecto: "Compilación" → "Firestore Database" → "Crear base de datos" (modo producción, cualquier región).
  3. "Configuración del proyecto" (ícono de tuerca) → agregar una app Web (ícono </>) → copiá el objeto firebaseConfig que te muestra.
  4. Pegalo acá abajo tal cual.
