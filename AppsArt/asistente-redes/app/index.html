Antes de arrancar, elegí cómo vas a guardar los datos.

Los datos quedan guardados solo en este navegador — sirve para probar la app antes de conectar Firebase. Podés conectar Firebase más adelante desde Configuración.

Conectar Firebase (Firestore + Storage)

Para que el generador (GitHub Actions) y este dashboard compartan los mismos datos:
  1. Entrá a console.firebase.google.com, creá un proyecto nuevo.
  2. "Compilación" → "Firestore Database" → "Crear base de datos" (modo producción).
  3. "Compilación" → "Storage" → "Comenzar" (guarda ahí las imágenes/videos generados).
  4. "Configuración del proyecto" (ícono de tuerca) → agregar una app Web (ícono </>) → copiá el objeto firebaseConfig.
  5. Pegalo acá abajo tal cual.
